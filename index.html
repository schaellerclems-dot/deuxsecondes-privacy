🛡️ Politique de Confidentialité

DeuxSecondes — Application de contrôle parental

Dernière mise à jour : août 2026

📱 Présentation de l'application

DeuxSecondes est une application de contrôle parental composée de deux applications distinctes :

  • DeuxSecondes (app enfant) : installée sur l'appareil de l'enfant mineur, elle applique les restrictions définies par le parent.
  • DeuxSecondes Parent : installée sur l'appareil du parent, elle permet de gérer et surveiller l'appareil enfant à distance.
⚠️ Limite d'âge : Cette application est destinée à la surveillance d'enfants de moins de 18 ans, avec leur connaissance et le consentement explicite de leurs parents ou tuteurs légaux. L'utilisation de cette application pour surveiller une personne majeure sans son consentement est strictement interdite et illégale.

🔍 Ce que l'application surveille

Transparence totale : L'enfant est informé de la surveillance via une notification permanente visible sur son appareil. Aucune surveillance cachée n'est effectuée.

L'application surveille les éléments suivants sur l'appareil de l'enfant :

Type de surveillance Méthode Destinataire
📍 Localisation GPS Toutes les 15 minutes Parent uniquement
📱 Applications installées À la demande Parent uniquement
⏱ Temps d'utilisation Toutes les 60 secondes Parent uniquement
🔔 Contenu des notifications Analyse locale + IA Extrait (80 car. max) si alerte
👁 Contenu visible à l'écran Service d'accessibilité Extrait si alerte uniquement

🤖 Analyse par Intelligence Artificielle

Pour détecter le cyberharcèlement, certains extraits de messages (80 caractères maximum) peuvent être analysés par une Intelligence Artificielle :

  • Le texte est envoyé à Anthropic (société américaine) via nos serveurs Firebase pour analyse.
  • Seul un extrait court est transmis — jamais le message complet.
  • L'analyse ne se déclenche que sur les applications de messagerie (WhatsApp, Discord, etc.).
  • Les données transmises à Anthropic sont soumises à leur politique de confidentialité.
En utilisant la fonctionnalité de détection de cyberharcèlement, vous acceptez que des extraits de messages puissent transiter vers des serveurs situés aux États-Unis (Anthropic) et en Europe (Google Firebase).

☁️ Stockage et sécurité

Les données sont stockées dans Firebase Firestore (Google Cloud Platform) avec des règles de sécurité strictes :

  • Seul le parent authentifié peut lire les données de ses enfants.
  • L'authentification est gérée par Firebase Authentication.
  • Le code PIN est stocké sous forme hachée (PBKDF2 + sel) — impossible à retrouver en clair.
  • Les données de localisation sont écrasées à chaque mise à jour.

Politique de confidentialité Google Firebase : firebase.google.com/support/privacy

⚖️ Base légale (RGPD)

Le traitement des données repose sur :

  • L'intérêt légitime du parent à protéger son enfant mineur (Art. 6.1.f RGPD)
  • L'autorité parentale prévue par l'article 371-1 du Code civil français
  • Le consentement de l'enfant, informé via la notification permanente affichée sur son appareil
Cette application est destinée aux enfants de moins de 18 ans. Pour les mineurs de 15 à 18 ans, le RGPD leur reconnaît des droits propres sur leurs données. Nous recommandons d'obtenir leur accord explicite avant installation.

✅ Droits des utilisateurs

  • Droit d'accès : toutes les données sont visibles dans l'application parent.
  • Droit de suppression : le parent peut supprimer un appareil enfant, ce qui supprime toutes ses données dans Firebase.
  • Droit d'opposition : la désinstallation de l'application enfant arrête immédiatement toute collecte.
  • Droit à la portabilité : les données sont accessibles via Firebase Console.

Pour exercer vos droits, contactez-nous à l'adresse indiquée ci-dessous.
