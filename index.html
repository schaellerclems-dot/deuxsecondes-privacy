🛡️ Politique de Confidentialité

DeuxSecondes — Application de contrôle parental

Dernière mise à jour : avril 2026

📱 Présentation de l'application

DeuxSecondes est une application de contrôle parental composée de deux applications distinctes :

  • DeuxSecondes (app enfant) : installée sur l'appareil de l'enfant, elle applique les restrictions définies par le parent.
  • DeuxSecondes Parent : installée sur l'appareil du parent, elle permet de gérer et surveiller l'appareil enfant à distance.
Cette application est destinée exclusivement à un usage familial, avec le consentement de toutes les parties. Elle n'est pas destinée à surveiller des personnes majeures à leur insu.

📊 Données collectées

L'application collecte les données suivantes sur l'appareil enfant :

Type de donnée Fréquence Destinataire
📍 Localisation GPS Toutes les 15 minutes Parent uniquement
📱 Apps installées À la demande Parent uniquement
⏱ Temps d'utilisation par app Toutes les 5 minutes Parent uniquement
🔔 Aperçu de notifications Uniquement si mot-clé détecté Parent uniquement
Concernant les notifications : le texte est analysé localement sur l'appareil. Seul un extrait de 80 caractères maximum est transmis au parent, et uniquement si un mot-clé interdit est détecté. Le contenu complet des messages n'est jamais stocké ni transmis.

🔒 Utilisation et partage des données

  • Les données sont transmises exclusivement au compte parent associé.
  • Aucune donnée n'est vendue, partagée avec des tiers ou utilisée à des fins publicitaires.
  • DeuxSecondes n'affiche aucune publicité.
  • Aucun profil commercial n'est créé à partir des données collectées.

☁️ Stockage et sécurité

Les données sont stockées dans Firebase Firestore (Google Cloud Platform, serveurs européens disponibles) avec des règles de sécurité strictes :

  • Seul le parent authentifié peut lire les données de ses enfants.
  • L'authentification est gérée par Firebase Authentication (Google).
  • Les données de localisation et d'utilisation sont écrasées à chaque mise à jour — aucun historique n'est conservé au-delà de la journée en cours.
  • Le code PIN est stocké sous forme hachée (PBKDF2 + sel aléatoire) — il est impossible de le retrouver en clair.

La politique de confidentialité de Google Firebase est disponible à l'adresse : firebase.google.com/support/privacy

⚖️ Base légale et consentement

L'utilisation de DeuxSecondes est soumise aux conditions suivantes :

  • L'application doit être installée par un parent ou tuteur légal sur l'appareil d'un enfant mineur.
  • L'utilisation de cette application pour surveiller une personne majeure sans son consentement explicite est strictement interdite et potentiellement illégale selon la législation applicable.
  • En France, la surveillance d'un enfant par ses parents est légale dans le cadre de l'exercice de l'autorité parentale (article 371-1 du Code civil).

✅ Droits des utilisateurs (RGPD)

Conformément au Règlement Général sur la Protection des Données (RGPD), vous disposez des droits suivants :

  • Droit d'accès : toutes les données sont visibles dans l'application parent.
  • Droit de suppression : le parent peut supprimer un appareil enfant depuis l'application, ce qui supprime toutes les données associées dans Firebase.
  • Droit de portabilité : les données sont accessibles via Firebase Console.
  • Droit d'opposition : la désinstallation de l'application enfant arrête immédiatement toute collecte de données.
